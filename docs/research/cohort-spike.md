## RISKS (top 5)
1. No operator-to-source mapping, no Form XObject boundary events: redaction must rewrite specific operators in specific content streams. Hayro Device gives geometry + glyph but no stream id/offset; `Instruction` has no span; `page_stream()` merges streams. Mitigation: FORK `hayro-syntax` + `hayro-interpret` (vendor under foliark, ~50-90 LOC additive: offsets, `Device::begin_operator(stream_id, range)`, stream-id stack through recursion, per-stream offsets); submit upstream PR in parallel. Fallback own module: own content-stream tokenizer for spans (needs object parser; `reader` module is `#[doc(hidden)]`, not stable) and correlate by operator order (fragile).
2. Text identity is incomplete: no raw char code, no font ref, Unicode may be None or multi-char (`BfString::String`, ligatures), Type1 `font_data()` is None, hidden-OCG text never reaches the Device (interpreter filters it). Redaction by search will miss or mis-map. Mitigation: patch getters for `char_code` and font `ObjRef` (~15 LOC, same fork); own module for a text-extraction pass that ignores OCG visibility (add `InterpreterSettings.ocg_override` in fork, ~10 LOC) so hidden text is still found and redacted; keep our own ToUnicode fallback table.
3. Writer: hayro-write is not usable for modified graphs (re-synthesizes /Contents, drops catalog data, internal API, drops encryption). Mitigation: own module `foliark-writer` on pdf-writer 0.15 (~200-300 LOC): reachability walk via `Dict::entries()`/`MaybeRef`, substitution map for replaced streams/images, byte-exact pass-through of untouched `raw_data()`, rewrite xref fresh, and an explicit policy for encryption (output unencrypted) and for objects that fail to load (hard error, never skip).
4. Silent failure on bad streams: flate garbage gives `Ok(empty)`, `page_stream()` swallows errors, `objects()` skips unreadable objects. A damaged page could look text-free and be "redacted" to blank, or content could be dropped on save. Mitigation: own module: wrap `Stream::decoded()` plus decoded-length/EOF sanity checks and `warning_sink`; fail closed with typed errors; golden tests with truncated/corrupt streams; upstream issue for a strict mode.
5. WASM payload and dependency drift: 5.6 MB raw / 1.8 MB gz (4.9 / 1.2 MB without embedded fonts+CMaps), 0.x APIs that break per minor (hayro-write/interpret explicitly internal), duplicate skrifa/fearless_simd, parley pulls ICU data. Mitigation: pin with `=`; vendor fork; lazy-load wasm (renderer only on demand); try opt-level "z" + wasm-opt; make fonts/cmaps loadable from JS (`font_resolver`/`cmap_resolver` are already closures) instead of embedded; prefer harfrust+skrifa over parley; evaluate render-less build to measure interpret-only size.
