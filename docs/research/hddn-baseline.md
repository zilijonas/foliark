## 2. Worker protocol (`src/types/worker.ts:166-218`, handlers `router.ts:665-691`)

All requests carry `requestId:number`; the worker serializes whole requests (`redactor.worker.ts:39-42`) and python calls via `runPythonTask` (`state.ts:122`). Fatal wasm/pyodide error sets `documentFaulted` (`state.ts:134`, `redactor.worker.ts:9-16`); every later request then fails with `import-rollback-failed` and `recoverable:false`.

| Request | Payload | Responses | Touches PyMuPDF |
|---|---|---|---|

| PRELOAD_TOOLING | `{ocrLanguages[]}` | TOOLING_STATUS, PROGRESS | boot only; OCR/asset warmup |
| TOOLING_STATUS | `{ocrLanguages[]}` | TOOLING_STATUS `{ocrLanguages, missingOcrLanguages, offlineReady}` | no |

| CONTINUE_OCR | `{importId?, ocrLanguages[]}` | PDF_LOADED | preview render for OCR (INFERRED; tesseract.ts not read) |
| COMMIT_IMPORT | `{importId, allowIncompleteOcr?}` | READY | `commit_pending_import` |
| CANCEL_IMPORT | `{importId}` | READY | `discard_pending_import` |

ArrayBuffer values in payloads are transferred (`state.ts:75-87`).

Staging/transaction model (`document-import.ts`, python `pyodide.ts:373-462`): LOAD_PDF opens a candidate doc, extracts every page, then `activate_pending_import` swaps context; `suspend`/`activate`/`commit`/`discard` swap the 6-tuple `(current_doc, current_bytes, _edited_doc, _edit_list, _fallback_fonts, _repaired_font_cache)`. Engine needs: multiple open documents, cheap switching, close-on-discard.

## 3. PyMuPDF surface (embedded Python + JS pdf-lib)

Distinct call tokens (PyMuPDF 1.26.3): `pymupdf.open` x6, `Rect` x12, `Font` x5, `Matrix` x3, `Point` x3, `TextWriter`, `csGRAY`, `PDF_ENCRYPT_NONE`, `PDF_REDACT_IMAGE_NONE`, `PDF_REDACT_LINE_ART_NONE`, `FileDataError` x2, `TOOLS.set_small_glyph_heights`, plus doc/page methods (get_text x5, get_pixmap x3, apply_redactions x3, add_redact_annot x3, get_texttrace x2, get_image_info x2, get_fonts, extract_font, tobytes x3, authenticate, set_rotation x4, update_stream, xref_*, embfile_*) and **low-level MuPDF object API** (`pymupdf._as_pdf_document`, `pdf_load_object`, `pdf_dict_gets/dels/get_val/get_key/len`, `pdf_array_get/len`, `pdf_is_dict/array/indirect`, `pdf_to_name/num/int`, `pdf_resolve_indirect`, `pdf_trailer`, `pdf_catalog`, `pdf_open_stream_number`, `mupdf.ll_pdf_get_xref_entry`, `mupdf.uchar_array`, `raw_to_python_bytes`, `page.get_contents`). Count: ~16 distinct `pymupdf.*` symbols, ~35 distinct doc/page methods, ~18 low-level pdf_* object calls (about 98 grep-visible call lines in the helper text, `grep` regex over pyodide.ts).

### 3.1 Load / open (`pyodide.ts:421-462`)
- Precheck in code, before engine: bytes start with `%PDF-` and `%%EOF` within the last 1024 bytes, else `malformed-pdf`.
- `pymupdf.open(stream=data, filetype="pdf")`; `FileDataError` -> `malformed-pdf`.
- **Repair is rejected**: `candidate.is_repaired` true (before AND after extraction, lines 432, 449) -> `malformed-pdf`. Foliark must report "repaired/recovered xref" as a flag, and HDDN refuses these (fixtures malformed-truncated, malformed-xref).
- Password: `needs_pass`; None -> `password-required`; `authenticate(pw)` false -> `password-incorrect`; then page_count > max_pages -> `too-many-pages`; then `candidate.tobytes(encryption=PDF_ENCRYPT_NONE)` re-opened as an unencrypted baseline (replay/export later opens `current_bytes` with no credential). Password variable is nulled in `finally` and deleted from the JS payload (`router.ts:219`). Encrypted source is therefore decrypted into memory bytes; the output is never re-encrypted.
- `max_pages` = `APP_LIMITS.maxPages` 30 (also `maxFileSizeMb` 25) from `src/lib/app-config.ts:3-7`; hard-limits fixture many-pages-1001.
- `MemoryError` -> `resource-exhausted`.

### 3.2 Page info
`page.rect` (width/height, **after rotation**, points), `page.rotation` (0/90/180/270 clockwise), `page.rotation_matrix`, `page.derotation_matrix`, `page.number`, `doc.page_count`, `doc[i]`. No cropbox/mediabox getter is called directly: CropBox handling is implicit in `page.rect` and in the comment "PyMuPDF extraction uses unrotated CropBox-relative coordinates" (`pyodide.ts:190`). `page.set_rotation(0)` temporarily during render (`unrotated` param, never passed by router: unused) and redaction (comment line 1155: "In bundled MuPDF, rotated CropBoxes can offset the generated fill").

### 3.3 Text extraction (`_extract_document`, `pyodide.ts:265-371`)
- Exactly ONE extraction call per page: `page.get_text("words", sort=True)`. Tuple fields consumed: `x0,y0,x1,y1,text,block_no,line_no,word_no` (indices 5-7 optional with fallbacks). Flags beyond `sort=True` are default (default flags set UNVERIFIED for 1.26.3; README "Unicode offset regression" documents ligature handling but was truncated in my read).
- `pymupdf.TOOLS.set_small_glyph_heights(True)` is set globally at module load (`pyodide.ts:1187`): word box heights follow font size, not ascender/descender. This changes every bbox and every redaction rect; Foliark must match or define a deliberate equivalent.
- Per word: `text = " ".join(text.split())`; empty words dropped. Page `textContent` = words joined by single space. `start`/`end` = **UTF-16 code-unit** offsets into `textContent` (computed via `len(text.encode("utf-16-le","surrogatepass"))//2`, lines 299-301), half-open. `charCount` = same units.
- Output per word `TextSpan`: `{id:"span_{page}_{wordIdx}", pageIndex, text, box:{x,y,width,height} normalized 0..1 in DISPLAY space, pageRotation, source:"native", confidence:1, start, end, blockIndex, lineIndex, wordIndex}` (`types/detection.ts:62-75`).
- **No font name, size, color, origin, char list or per-glyph data reaches TS from extraction.** Spans are WORDS.
- Box conversion: `Rect(native) * page.rotation_matrix` then divided by `page.rect.width/height`, clamped to [0,1] (`_native_rect_to_display_box`, `_normalize_box`, lines 177-195). Inverse for redactions/edits: `denorm(box, page.rect) * page.derotation_matrix` (194-195, 1202-1208).
- Garbled-text detection (`_is_native_text_garbled`, 200-242): replacement chars (U+FFFD) > 2 -> garbled; or lowercase ratio < `nativeTextMinLowercaseRatio` (0.1) AND vowel-token ratio < `nativeTextMinVowelTokenRatio` (0.7), only when letters >= `nativeTextGarbledMinLetters` 40. Vowel set `aeiouyąęėįųūœ`. Garbled page -> `lane:"ocr"` + warning `worker.warnings.garbledPage`.
- Streaming: `page_sink(json)` per page `{page, spans, warnings}` (62480e5), pages must arrive in order (`router.ts:177`).

### 3.4 Page classification native vs scanned (`pyodide.ts:318-354`)
- `meets_thresholds = spans >= minTextSpanCountForNativeText (8) and len(textContent) >= minTextCharactersForNativeText (64)`.
- `sparse_but_digital = not meets and spans > 0 and _max_image_coverage(page) < 0.5`; coverage = largest `page.get_image_info()` bbox area / page area (get_image_info failure -> 0.0).
- `lane = "searchable"` if (meets or sparse_but_digital) and not garbled, else `"ocr"`. Page record: `{pageIndex,width,height,rotation,lane,previewScale,textLayerStatus:"native"|"missing",ocrStatus:"skipped"|"queued",textContent,charCount,spanCount}`. Spans of OCR-lane pages are discarded. Hidden OCR text (fixture hidden-ocr-text) is therefore treated as native text; engine gives no render-mode info today.
- Python defaults (0.20/0.25) are overridden by app-config values passed from router (`router.ts:188-216`).

### 3.5 Rendering
- Preview: `page.get_pixmap(matrix=Matrix(scale,scale), alpha=False)` then `pix.tobytes("png")` (`pyodide.ts:464-477`). RGB, no alpha, default colorspace, default annotation rendering (annots drawn: default `annots=True`, UNVERIFIED). scale 1.35 preview, 2 for flattened export (`exportScale`), 1.5 + `csGRAY` for signature detection, 2 with `clip` for background sampling. Pixel size = display points x scale. PNG bytes are copied into an owned ArrayBuffer and transferred to UI. Renders the **edited** doc if one exists (`_edited_doc or current_doc`), so previews reflect pending text edits.
- `detect_signature_regions(page_index, text_boxes_json, min_y_ratio)`: gray pixmap, downscale to 540 px by stride sampling, binarize at 210, flood-fill clusters; returns up to 4 `{box (normalized), density, width_px, height_px}`. Pure Python pixel loop over `pix.samples` (needs: grayscale render + raw sample access).

### 3.6 Search
No PyMuPDF `search_for` is used. Detection is JS regex/rules over `textContent`/spans (`src/lib/detection/*`, `DETECT` handler). Redaction targets are word boxes from spans. Foliark v1 needs no search API for HDDN.

### 3.7 Redaction (`export_redacted_pdf`, `pyodide.ts:1119-1180`; edits' erase `1952-1968`)
- Boxes are normalized display boxes `{pageIndex, box}` flattened from confirmed detections/manual redactions (`state.ts:172`). Converted per page to native rects (derotation).
- Per page: `page.set_rotation(0)`, then for each rect `page.add_redact_annot(rect, fill=(0,0,0))`, then ONE `page.apply_redactions()` with **all default flags** (images/graphics/text unspecified: numeric defaults in 1.26.3 not asserted in repo code; independent harness verifies image pixels under the rect are removed and text removed), rotation restored in `finally`.
- Semantics HDDN relies on: text under rect deleted from content stream (not painted over); intersecting raster image pixels blanked (README "recovered image-pixel removal", `check-coordinate-ocr.py`); black fill; shared images across pages must not leak (fixture shared-image); vector graphics under rect handled (fixture shared-vector). Text edits run FIRST, redactions SECOND so privacy wins over inserted replacement text (`1133-1135`).
- Text-edit erase passes use `add_redact_annot(word_rect, fill=<sampled rgb or None>)` + `apply_redactions()` default, or for rects over images `add_redact_annot(rect)` + `apply_redactions(images=PDF_REDACT_IMAGE_NONE, graphics=PDF_REDACT_LINE_ART_NONE)` (keeps image/vector under the text).

### 3.8 Sanitization (native export only)
Order in `export_redacted_pdf`: `_assert_native_export_supported_structures` -> `_strip_native_accessibility_payloads` -> edits -> redactions -> `_strip_native_nonvisual_document_channels` -> `tobytes`. The code itself says (`pyodide.ts:707`): "Partial nonvisual-channel removal; NOT a full hidden-content sanitizer."
- `_strip_native_nonvisual_document_channels` (706-761): delete trailer `Info`; catalog keys `Metadata, Outlines, OpenAction, AA, AF, Collection`; all `embfile_names()` via `embfile_del`; `Names/JavaScript`; per page `Thumb, Metadata, PieceInfo, AA, AF`; every annotation (walking `IRT/Popup/Parent`, cycle-safe): delete `A, AA, PA, Dest`; for `Text/Popup` also `Contents,T,Subj,RC,CreationDate,M,NM`; for `FreeText` `T,Subj,CreationDate,M,NM` (annotation appearance streams preserved); every live xref: delete `Metadata, PieceInfo, AF`; recursively delete `Private` from `Font`/`FontDescriptor` dicts. Does NOT call `doc.scrub()` or `set_metadata`.
- `_strip_native_accessibility_payloads` (959-1062) + `_strip_accessibility_content` (803-957): tokenizes decoded page/Form/Pattern content streams (budgets: 4 MiB per stream, 16 MiB total, 200000 tokens; filters limited to ASCIIHex/ASCII85/Flate/LZW/RunLength + abbreviations), removes `/ActualText` and `/Alt` marked-content properties and dictionary keys, deletes replacement strings by xref, rejects retained shared references, rewrites streams via `doc.update_stream`. Raises `NativeInvisibleTextUnsupported` for invisible text (`Tr` render modes, `reject_invisible`) and unsupported filters.
- `_assert_native_export_supported_structures` (1072-1106): refuses `OCProperties`/`OCG`/`OCMD` -> `NativeOptionalContentUnsupported`; refuses `AcroForm` or any `Widget` -> `NativeFormExportUnsupported`; indirect font `Private` -> RuntimeError. Scans every live xref (skips free/null xref entries via `ll_pdf_get_xref_entry`).
- `native_export_has_forms()` (1109) pre-flights those checks on `current_bytes`.
- Flattened mode bypasses all of this by never copying original objects (see 3.10).

### 3.9 Paragraph text edit (the heaviest engine use, `pyodide.ts:1182-2037`)
Features requested of the engine, per edit (`prepare_paragraph_edit` 1802-1858, `_apply_text_edits` 1893-1984, `set_text_edits` 1991-2037):
1. Style: `page.get_text("dict", clip=rect±2pt)`; first dict span intersecting the union rect wins; fields consumed `font` (name), `size`, `color` (sRGB int -> 0..1 tuple), `flags` (bit 2 italic, 4 serif, 8 mono, 16 bold), `origin[1]` (baseline y), line `dir` (must be (1,0) within 0.001, else `rotated-text`), `bbox`. `mixedStyle` = >1 distinct `(font,size,color,flags)` among covering spans. Returns `no-style` if none.
2. Original text: `page.get_texttrace()` chars `(unicode, glyph_id, origin, bbox)` inside word rects (+1pt pad), overprint de-dup (same char whose box overlaps previous) to repair faux-bold doubling that `get_text("words")` mangles ("Invoice" -> "InInvoic oice"). Failure -> `originalText: null`.
3. Embedded font reuse: `page.get_fonts(full=False)` tuple `(xref, ext, type, basefont, name, ...)`, name-normalized unique match (strip `ABCDEF+` subset tag, lowercase alnum; exact, then prefix, then the page's only font); `doc.extract_font(xref)` -> `(name, ext, type, bytes)`; unicode->glyph map from `get_texttrace` chars (`cp in 0x20..0xFFFE`, gid != 0); pure-python **`_repair_font_for_browser`** (lines 14-175) rebuilds a `(3,1)` format-4 cmap + OS/2 table (`_build_cmap_format4`, `_build_os2`, `_sfnt_checksum`, table padding) so the same TTF works in browser and in `pymupdf.Font(fontbuffer=...)` (`font.is_writable` required). Any failure degrades silently to the fallback ladder. Cache key `(page.number, normalized font)`. This is the "ToUnicode rebuild": it rebuilds the **font's cmap**, not the PDF ToUnicode CMap object.
4. Font ladder per glyph: embedded (`has_glyph`) -> bundled fallback family -> Base-14 (`pymupdf.Font(fontname=helv|hebo|heit|hebi|tiro|tibo|tiit|tibi|cour|cobo|coit|cobi)`). Family picked from font name (`calibri->Carlito`, `cambria->Caladea`, `georgia->Gelasio`, times/roman/minion/garamond->LiberationSerif, courier/consol/mono->LiberationMono, arial/helvetica/verdana/tahoma->LiberationSans; flags 8 mono, 4 serif, else sans) + style suffix. Fallback TTFs (24 files, 7.86 MB) are fetched by JS (`edit-fonts.ts:37-58`, `fonts/pdf/<File>.ttf`) and registered via `register_fallback_font(pick, bytes)`. `localFontPick` = user-chosen font; base64 bytes of embedded/fallback fonts go back to the UI so the browser editor renders identically.
5. Metrics used: `Font.text_length(ch, fontsize)`, `Font.has_glyph`, `Font.descender`, `Font.buffer`, `Font.is_writable`.
6. Layout (all in PDF points on UNROTATED page; rotated pages rejected): wrap width extends to the page's content right margin (max word x1) unless a word sits beside; vertical budget to next word below or symmetric bottom margin; line step = median baseline delta from dict spans (`>1pt`), else 1.2 x size; `maxLines = int((bottom_limit+0.1-baseline-descent)//lineStep)+1`; greedy wrap by per-glyph advance; leading-space indents, hard `\n` breaks.
7. Background: if rect intersects any `get_image_info()` bbox -> keep underlying pixels (no fill); else sample ring around rect via `get_pixmap(Matrix(2,2), clip, alpha=False)`, median RGB, uniform if >=85% of ring within +-24 per channel, else white + warning `worker.warnings.editBackgroundMismatch`.
8. Insert: `pymupdf.TextWriter(page_rect)`; `writer.append(Point(x, baseline), run, font=, fontsize=)` per same-font run; `writer.write_text(page, color=rgb)`. NOT `insert_text`/`insert_htmlbox`. Original font size kept; no scaling to fit (edit rejected as `editSkippedNoFit` instead).
9. Replay model (`set_text_edits`): authoritative edit list; rebuild `_edited_doc` from pristine `current_bytes` and replay ALL edits; on any rejection nothing changes (`accepted:false`, `rejectedEdits`). Then re-extract changed pages with thresholds 1/0/0 so edited pages stay in native lane. Returns re-extracted `pages` + `spans` for changed pages only.
10. Rejections (reason keys): `editSkippedNoStyle` (no span or non-horizontal), `editSkippedNoFont` (glyph not covered by any font), `editSkippedNoFit`; ValueError on non-BMP / RTL ranges (U+0590-08FF, FB1D-FDFF, FE70-FEFF) and on rotated pages (`_validate_edit_*`, 1872-1891); same check in TS (`geometry.ts:139-150`).
11. Normalization: per line keep leading-space indent, collapse interior whitespace, drop trailing; mirrors `normalizeReplacement` in `ParagraphEditor.tsx`.

Return shape `ParagraphEditMetrics` (`types/worker.ts:93-114`): `status, fontSizePt, lineStepPt, colorRgb, bold, italic, mixedStyle, pageWidthPt, pageHeightPt, originXNorm, topNorm, firstBaselineNorm, wrapWidthNorm, maxHeightNorm, maxLines, fallbackPick, embeddedFontB64, localFontB64, fallbackFontB64, originalText`.

### 3.10 Flattened export fallback (pdf-lib, `export-renderer.ts:73-174`)
- Per page: `render_page_png(pageIndex, exportScale=2)` (reads edited doc), decode with `createImageBitmap`, paint `#050505` rects on OffscreenCanvas using exact BigInt-decimal rasterization of normalized boxes (`rasterAxis`, 34-64: rejects NaN, out of [0,1], extent <= 0), re-encode PNG.
- `PDFDocument.create()`; `embedPng`, `embedded.embed()` (releases decoded channels), `addPage([page.width, page.height])` (display points, post-rotation: output has NO /Rotate), `drawImage` full page, then `drawRectangle` rgb(5/255) over each box (bottom-left y = `(1-y-h)*H`). `output.save()`.
- pdf-lib is the only JS PDF dependency (`package.json` `"pdf-lib": "^1.17.1"`). Info/Producer/dates that pdf-lib sets by default: UNKNOWN whether HDDN overrides (no setProducer/updateMetadata seen in the file). Output has no text layer by design.
- The flattened path needs from Foliark only: render to PNG/RGBA at scale; optionally "create image-only PDF". The UI reaches flattened only after acknowledgement (`useExportRunner.ts:148`); HDDN-8 memo says flattened is UI-unreachable in current C, worker-only.

### 3.11 Save / serialize (`pyodide.ts:1165`)
`doc.tobytes(garbage=4, deflate=True)`. Not used: `clean`, `linear`, `incremental`, `encryption`, `scrub`, `pretty`, `use_objstms`. `garbage=4` rewrites the whole file, dropping unreferenced objects and deduplicating, which also removes old incremental revisions (fixture incremental-revision). Post-save self-check: reopen exported bytes and compare `page_count` (1170-1178). Router then asserts `assertExportedPdfBytes` (`router.ts:634`; body UNKNOWN) and transfers the buffer (native bytes may alias WASM, so they are copied via `toOwnedArrayBuffer`, `router.ts:636-644`).

## 4. Downstream consumers and exact data contract

- **Coordinate space on the wire**: ALL boxes (`BoundingBox {x,y,width,height}`) are normalized 0..1 fractions of the **displayed (rotated) page**, origin TOP-LEFT, y down. `PageAsset.width/height` are `page.rect` points after rotation; `rotation` is clockwise degrees, informational (boxes already rotated). Native PDF-space conversion lives only in Python (`_native_rect_to_display_box` / `_display_box_to_native_rect`). Edits/redactions return to Python as the same normalized display boxes. A Foliark API that takes/returns **PDF user-space points with explicit rotation matrix** can replace this if HDDN keeps a thin adapter; the normalization must reproduce the `rotation_matrix`/CropBox semantics exactly (fixture rotation-crop; README coordinate regression `test-coordinate-mapping.py`, `test-coordinate-wasm.mjs`, `check-coordinate-ocr.py`).
- **Text indices**: `start`/`end` half-open UTF-16 code units into the page `textContent` (single-space joined words). Required by detection and span highlighting (`types/detection.ts:57,70`; commit `4cf6e3d`; README "Unicode offset regression" with 6 additive fixtures, non-BMP surrogate pairs).
- **Consumers**: `src/lib/detection.ts` + `detection/rules/*`, `name*.ts` (regex over `textContent`, mapping matches back to spans by `start/end`; internals not read); `src/lib/text-edit/geometry.ts` groups native spans into paragraphs using `pageIndex_blockIndex_lineIndex` keys, `orderSpansVisually`, line gap <= 0.9 x line height, 2% horizontal tolerance (lines 20-130), builds `TextEditWire {id,pageIndex,boxes[],replacementText,localFontPick}` (152); OCR merge: `src/workers/lib/tesseract.ts` produces `source:"ocr"` spans with the same `TextSpan` shape (file not read, UNKNOWN details, `bootstrapOcrLayers` in `state.ts:49`). So native extraction MUST provide: stable block/line/word indices where blocks/lines reflect the producer's text-run grouping, words in reading order (`sort=True`: top-to-bottom then left-to-right), and no empty words.
- Signature detection (`signatures.ts` + `detect_signature_regions`) consumes normalized text boxes and a gray render.
- Fingerprint is a JS FNV-1a over sampled bytes (`state.ts:156`), engine-independent.

## 7. Reusable HDDN behavior to keep (belongs above or beside the engine)

- Import transaction with generation guard (`document-import.ts`): stage -> pending -> commit/cancel; late cancel cannot discard newer candidate (`currentAttemptId`), `retiredImportIds`, password retry does NOT retire the attempt, rollback failure sets `documentFaulted` (`import-rollback-failed`). Engine needs cheap discard of a candidate and close of old docs.
- Worker client recovery (`src/lib/worker-client.ts`): per-request pending map, ERROR -> `WorkerRequestError(notice, code)`, `recoverable` flag, fatal path terminates worker, rejects all pending, sets `recoveryRequired`, blocks `APPLY_REDACTIONS` until a fresh worker is installed (lines 154-201). A fresh worker must be able to rebuild state from bytes + edit list.
- Save outcomes (`src/features/redactor/hooks/useExportRunner.ts`): `ExportOutcome` = `generated` -> `handed-off {method: file-picker|browser-download}` | `failed {stage, code, error}` | `cancelled`; flattened requires `acknowledgedFlattenedConsequences`; picker `showSaveFilePicker` with fallback to anchor download; in-flight de-dup (`inFlight` ref). Generation != handoff: engine must return bytes only; UI owns "saved".
- Cancel semantics: queued requests are serialized; cancel of an active python call is not preemptive (HDDN-8: "scan queued cancellation is not active-OCR preemption"); terminate+reload is the hard cancel. Foliark API should be per-page or chunked so cooperative cancellation is possible, or accept terminate.
- Offline asset caching (`src/lib/airplane-assets.ts`, `airplane-cache.ts`, `public/airplane-sw.js`): versioned cache name, explicit asset lists (pyodide files at lines 27-32; `PDF_EDIT_FONT_ASSETS`; tooling version string `getAirplaneModeToolingVersion`, 128-134), shell-manifest sha256 placeholder + ready marker (`.airplane-shell-ready-v15`). Foliark's wasm + any fonts must plug in as an asset group.
- Free allowance ledger (`src/lib/free-allowance.ts`, `a4e1192`) is product logic independent of the engine.
- Streaming per-page extraction via `page_sink` (62480e5) to bound memory.
- User-facing error taxonomy as i18n keys (see section 2).

## 8. Known gaps and unresolved items relevant to Foliark

1. Sanitization is explicitly partial (`pyodide.ts:707`). Known-unhandled by design: native export REFUSES (does not clean) AcroForm/widgets, optional content (OCG/OCMD), invisible text render modes, unsupported accessibility stream filters. Not cleaned/covered: XMP inside objects other than listed keys is deleted only by key name; structure tree/tagged-PDF content beyond ActualText/Alt (UNKNOWN), embedded fonts' other private data, hidden layers, JavaScript in forms. README calls it "a partial native-export checkpoint". Foliark v1 must either implement these or keep HDDN's refusals as API-visible capability errors.
2. HDDN-8 historical: shared-image native **cyclic Page references** recorded; fix PR14/97b46a95 "separate from frozen C" (merged into export-buffer? UNKNOWN).
3. Font fidelity defect (HDDN-104, open): source subset DejaVuSans 12 pt becomes Liberation Serif Regular for newly typed letters in preview and saved PDF; first edit offers no similar-font choice. `1871d54` fix exists in C but this case is not a pass. HDDN-88 acceptance not generalized.
4. Edit limits: rotated pages and non-horizontal text rejected; non-BMP/RTL replacement rejected; multi-style words use first covering span (`mixedStyle` flag); no scaling-to-fit.
5. `pymupdf` AGPL/commercial license: HDDN-8 states "commercial license ... remain separate" open item, and `d7e7d68` preserves MuPDF notices; this is the business driver for Foliark. HDDN-84 (PyMuPDF package backlog) not read.
6. RESET leaves committed python document/bytes alive until replaced (HDDN-8 memo); heap reclamation unproven.
7. Flattened mode: UI-unreachable in current C, worker-only evidence; pdf-lib metadata behavior UNKNOWN; page /Rotate and CropBox of source are not preserved (image-only pages at display size).
8. Encrypted inputs are decrypted for the session and exported unencrypted; no re-encryption or permission preservation.
9. Repaired PDFs are rejected (no tolerant parse path); Foliark must surface "repaired" distinctly and not silently fix.
10. UNKNOWN items to resolve before freezing API: PyMuPDF 1.26.3 numeric defaults of `apply_redactions(images, graphics, text)`; default `get_text` flags for "words"/"dict"; whether annotations are rendered by `get_pixmap`; `assertExportedPdfBytes` rules (`router.ts`); OCR page-image source; HDDN-84/HDDN-23 final acceptance memos; per-op timings; export-buffer vs graphics-lifetimes conflict resolution.
