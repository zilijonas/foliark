# Foliark v1 contract (frozen 2026-10-22, NEW-3)

FROZEN: changes need an ADR in `docs/adr/`. Inputs: `docs/research/hddn-baseline.md` (HDDN `2fe0f9a`), `docs/research/cohort-spike.md`, `docs/plan/*`, ADR 0001. MUST/NEVER are normative. Terms used with one meaning: display space (§2), cluster (§3.1), region (§5), revision (§4).

## 0. Global rules
1. Every operation completes or rejects with a typed `FoliarkError` and yields no partial output. No silent fallback, rasterization, skip, empty-on-decode-failure or shrink-to-fit.
2. Anything not specified as supported is a typed refusal (§12). Capability is tri-state (§11); export support is NEVER inferred from preview.
3. Native output is a fresh, reachable-only, unencrypted, non-incremental, allowlisted file (§8). Privacy wins: edits, then redactions, then sanitization.
4. Deterministic: same input + ChangeSet + policy + registered fonts + SDK version = identical bytes.
5. No document content in logs, caches, telemetry or requests. The SDK fetches only wasm, worker script and the optional CMap pack (§10.3).

## 1. Public TypeScript API (`packages/sdk`, headless ESM)
DTOs are defined once in Rust (`foliark-model`, serde camelCase, ts-rs) and generated to TS; shapes below are normative. All geometry is display space. `page` = 0-based index (out of range -> `INVALID_ARGUMENT`). Every long call takes `signal?: AbortSignal` (abort -> `CANCELLED`, state unchanged).

### 1.3 Render

`width = max(1, round(clip.width*scale))` (same for height); each side <= 16384 and `width*height <= maxRenderPixels`, else `LIMIT_EXCEEDED`. Pixel (i,j) covers display rect `[clip.x+i/scale, clip.y+j/scale, 1/scale, 1/scale]`. Renders the current revision (edits applied, redactions NOT burned in, §5.7). `complete:false` iff any warning; preview still returns pixels, raster export refuses (§7).

## 2. Coordinate contract
**Display space**: points (1/72 in) of the page as displayed; origin top-left, x right, y down; after CropBox, /Rotate, /UserUnit. `C=[cx0,cy0,cx1,cy1]` = CropBox ∩ MediaBox (normalized, inherited, missing CropBox = MediaBox); `w0=cx1-cx0`, `h0=cy1-cy0`; `u` = UserUnit (1); `r` = Rotate mod 360 (not a multiple of 90 -> `MALFORMED_PDF`). `W,H = r in {0,180} ? (u*w0, u*h0) : (u*h0, u*w0)`.

| r | userToDisplay [a,b,c,d,e,f] |
|---|---|
| 0 | [u, 0, 0, -u, -u*cx0, u*cy1] |
| 90 | [0, u, u, 0, -u*cy0, -u*cx0] |
| 180 | [-u, 0, 0, u, u*cx1, -u*cy0] |
| 270 | [0, -u, -u, 0, u*cy1, u*cx1] |

`displayToUser` = exact inverse. Rotation is clockwise, equal to PyMuPDF `rotation_matrix` over its CropBox-relative unrotated space (PyMuPDF ignores UserUnit; normalized boxes are UserUnit-invariant).
**HDDN normalized box** (`foliark-model::geom::normalize`): `nx=clamp01(x/W)`, `ny=clamp01(y/H)`, `nw=clamp01((x+width)/W)-nx`, `nh=clamp01((y+height)/H)-ny`; inverse `x=nx*W, y=ny*H, width=nw*W, height=nh*H`. A non-axis-aligned quad's box = axis-aligned bbox in display space.
**Unrotated crop space** (only for the §3.4 sort key): display space computed with r = 0.

## 3. Text contract
### 3.1 Clusters
Cluster = one shown glyph (one char code) + its Unicode string; the atomic unit of selection, search geometry, edit removal and redaction. Unicode: ToUnicode -> simple-font encoding / AGL name / `uniXXXX` (hayro chain) -> none. None, or a non-whitespace C0/C1 control -> one U+FFFD, flag `unmapped`. A multi-code-point mapping (ligature, decomposed accent) stays one cluster (flag `multiCodepoint`) whose UTF-16 units share its quad. NEVER divide a word or cluster rectangle; a range splitting a cluster reports `partialCluster:true` with the whole quad. Separately drawn base + mark = two clusters.
**Quad**: text-space x from glyph origin to origin + advance (Tc/Tw/Tz applied); y from `d` to `a`, where `a,d` = FontDescriptor /Ascent,/Descent / 1000 (fallback font hhea, then 0.8/-0.2); if `a-d > 1`: `a/=(a-d)`, `d/=(a-d)` (PyMuPDF small glyph heights, §3.6 tolerance). Mapped by Trm, CTM, userToDisplay.
**Excluded**: clusters whose quad is entirely outside the crop box; OFF optional content (with `includeOcgHidden` they are included, flagged, in that call only). Render modes 3 and 7 ARE extracted, flag `invisible`.

### 3.2 Style
`size = Tfs * hypot(c, d)` of the text matrix chain (Tm, CTM, userToDisplay). `color` = fill (stroke for modes 1/5) in sRGB. bold = ForceBold or /FontWeight >= 600 or name contains bold|black|heavy|semibold|demi; italic = Italic flag or ItalicAngle != 0 or name contains italic|oblique; serif = Serif flag; mono = FixedPitch flag.

### 3.3 Lines, words, blocks
Constants (`foliark-model::text::GROUPING`; em = larger size of the two neighbors): `SAME_LINE_PERP=0.5`, `NEW_LINE_BACK=0.5`, `NEW_LINE_FWD=5.0`, `WORD_GAP=0.2`, `BLOCK_GAP=1.5`.
1. Clusters in content order (Forms/Type3 inlined at their occurrence). A cluster continues the line iff same baseline direction (|cross| < 0.01), perpendicular offset <= SAME_LINE_PERP em, and gap from the previous advance end in [-NEW_LINE_BACK, +NEW_LINE_FWD] em.
2. Word breaks: whitespace clusters (White_Space; not emitted) and gaps >= WORD_GAP em. No empty words.
3. A line joins the current block iff same direction, baseline advanced in reading direction by (0, BLOCK_GAP em], and extents along the baseline overlap. `blockIndex` per page in content order, `lineIndex` per block, `wordIndex` per line (PyMuPDF semantics; HDDN `text-edit/geometry.ts` keys on page_block_line).

### 3.4 Order and joining
`words` are stably sorted by `(y1, x0)` of `box` in unrotated crop space (= PyMuPDF `get_text("words", sort=True)`); ties keep content order. `text = words.map(w => w.text).join(" ")`. Offsets are half-open UTF-16 code units (surrogate pair = 2). Cluster offsets index the same string. U+FFFD count in `text` feeds HDDN's garbled-page rule unchanged.

### 3.5 Hit test, select, search
`hitTest`: cluster whose quad contains p, else nearest within tolerance, else null. `select`: snap both ends to the nearest cluster; range = [min start, max end); one union quad per line. `search` runs in Rust per page over `text` with a reversible map (each normalized unit -> source code point -> whole cluster): N1 lowercase per code point only when it yields one code point (unless caseSensitive); N2 U+FB00-FB06 expanded; N3 if !diacriticSensitive, NFD and drop Mn; N4 ‘’‚‛ -> ', “”„ -> ", U+2010-2015 and U+2212 -> '-'. The query gets N1-N4. `wholeWord`: hit edges on word boundaries. No regex (HDDN keeps JS rules over `text`).

### 3.6 PyMuPDF parity (dev-only oracle)
On HDDN fixtures + corpus: identical `text` where no ligature/ToUnicode quirk applies; word boxes within 0.75 pt of PyMuPDF 1.26.3 words with small glyph heights; identical (block,line,word) keys on single-column pages. Accepted differences: block splits on multi-column/table pages, block placement of invisible OCR words, U+FFFD vs our AGL fallback.

## 4. Revisions, ChangeSet, plans
- `revision` starts at 0, +1 per accepted `applyChanges`. Every text/geometry result carries `revision`. `baseRevision != current` -> `STALE_REVISION`.
- Declarative and all-or-nothing: `textEdits`/`redactions` each replace their whole list; an omitted field keeps the current list; undo = resubmit an older list. Any rejection -> `accepted:false`, nothing changes.
- Edits replay from the source in array order; each edit's `rects` are evaluated on the state after the previous edits. Revision N's working copy = preserve-mode write (§8.3) of source + edits, reopened by the strict reader; extract/render/select/search read it.
- `text` redactions resolve against `baseRevision` text (before this ChangeSet's edits) to one region per line (bbox of the line's cluster quads) plus a must-remove cluster set, then are stored as regions. Redactions run only at export (§5), after edits.
- `ExportPlan` binds `{docId, generation, revision, mode, policyHash, fontRegistryVersion}`. `prepareExport` performs the whole export and holds the bytes (counted in `maxOutputBytes`); a stale binding at `export` -> `STALE_PLAN`. A new plan, `applyChanges`, `registerFonts`, `close` or reset frees older plans.

## 5. Redaction (native)
Pipeline: edits (working copy) -> annotation/widget flattening (§8) -> optional-content flattening -> redaction -> sanitization -> write -> verify. A region applies to one page occurrence; overlap is tested in display space.
1. **Text**: a cluster is removed iff `area(quad ∩ region) >= 0.02 * area(quad)` or it is in a must-remove set. Same for visible, invisible, Type3, inserted replacement text and text in Forms/patterns/flattened appearances. The showing operator is rewritten so survivors keep position within 0.01 pt (removed glyphs become TJ displacements incl. Tc/Tw). Whole clusters only.
2. **Images** (XObject, inline, in Forms/appearances): for an occurrence intersecting a region, every sample whose pixel square (display space) intersects it is erased: color 0 (black); SMask/Mask/SMaskInData samples set opaque; stencil (`ImageMask`) samples set unpainted. Re-encoded 8-bit DeviceRGB (DeviceGray if gray), SMask 8-bit DeviceGray, Flate (`IMAGE_REENCODED`). Inline images become an XObject drawn by `Do` in place of BI..EI. Shared image with untouched occurrences: the redacted occurrence gets a clone; survivors keep the original and are listed in `sharedSurvivors`.
3. **Forms** (incl. soft-mask groups, flattened appearances): an occurrence needing change is cloned (whole nested chain), never edited in place when shared. Unchanged Forms pass through byte-exact.
4. **Vectors** (ADR 0009). *Fills:* a filled path is one unit (all its subpaths together, under its own fill rule; subpaths whose bounds touch form a group, groups are independent). Its ink (the fill area) is subtracted from the regions in display space, the regions inflated by 0.01 pt, curves flattened to 0.01 pt, on a 1/1024 pt grid. (a) Ink entirely inside the regions -> the path is removed (`vectorSubpathsRemoved`). (b) Ink crossing -> the crossing group is replaced by the difference (disjoint contours, holes wind against their outer, valid under either fill rule), written back in the stream's own space (`vectorPathsCut`, loss `VECTOR_CUT_APPROXIMATED` when curves were flattened). (c) Ink clear of every region -> its operators stay byte for byte. Geometry is tested whether or not a clip hides it. No filled path is removed merely for crossing a region, so fills never produce collateral. A zero-area path (singular CTM) that reaches a region is removed. *Clips are geometry:* the outline of every `W`/`W*` path (painted, or `W n`) whose outline meets a region is replaced by the same difference (counted in `vectorPathsCut`); a clip that only encloses a region is left alone; one wholly inside the regions becomes an empty clip (`0 0 0 0 re W n`), as only content inside the regions was under it. A painted path's clip is written after its paint. *Strokes:* a stroke is expanded by kurbo in the path's own space with its own width, caps, joins, miter limit and dashes (the pattern restarts per subpath; the renderer's minimum device width is not applied), mapped to display space (exact under a non-uniform CTM) and treated as one non-zero ink per subpath. Same classes as fills: ink inside -> removed; crossing -> the subpath's stroke is replaced by a filled outline of the difference (`f`, non-zero, inside `q ... Q`, painted with the stroking colour mirrored as fill operators; dash, cap and join structure is gone, `vectorPathsCut`, loss `VECTOR_CUT_APPROXIMATED`); clear -> its operators stay byte for byte (as `S`). In `B`, `B*`, `b`, `b*` the fill part is cut as a fill and the stroke part as a stroke, painted fill then stroke. A cut stroke whose paint cannot be reproduced as a fill -> `REDACT_VECTOR_UNSUPPORTED {feature, pages}`: `strokeColorInherited` (no stroking colour operator in force in the stream; the first content stream of a page starts from black), `strokePattern` (pattern as stroking colour), `strokeAlphaDiffers` (`CA` differs from `ca`), `strokeBothAlpha` (a `B` variant with any alpha under 1 in which fill or stroke changes). A stroke over 100,000 dashes -> `LIMIT_EXCEEDED {vectorDashes}`. No stroke is removed merely for crossing a region. A path with all ink removed paints nothing; its clip is cut as above. Non-painting clip paths that miss every region are kept. `sh` is kept (procedural, covered by the fill). Tiling-pattern paint intersecting a region whose cell contains text or images -> `REDACT_PATTERN_UNSUPPORTED`. A group over 250,000 flattened vertices, a display coordinate beyond 131,072 pt, or work over `maxWorkUnits` -> `LIMIT_EXCEEDED {vectorVertices | vectorCoordinate | vectorDashes | maxWorkUnits}`, no output. A clip the interpreter drops as covering its whole bounding box has no model item and stays (it clips nothing).
5. **Fill**: each region with non-null `fill` (omitted = black) gets an opaque DeviceRGB rectangle painted last, outside all clips. Removal never depends on it: `fill: null` removes the same content and paints nothing.
6. **Fonts touched by removal** (edits or redaction): ToUnicode rebuilt to surviving codes; /CharSet and /CIDSet dropped; TrueType glyphs no longer referenced by surviving content emptied in place (gids stable); unused Type3 CharProcs dropped; CFF/Type1 programs kept and listed in `kept.fontsWithGlyphInventory` (`FONT_GLYPH_INVENTORY_RETAINED`).
7. **Verify** (in-engine, not a privacy certificate): strict reparse, equal page count, no re-extracted cluster meeting rule 1 for any region, no unmodified image occurrence intersecting a region, no vector geometry inside a region except our own fills; failure -> `REDACT_VERIFY_FAILED`, no output. To preview the result, open the exported bytes as a new document.

## 6. Paragraph editing
### 6.1 Selection and eligibility
`prepareParagraph` and `TextEdit.rects` select clusters whose quad center lies in any rect. None -> `EDIT_NO_STYLE`. Every selected cluster must have display baseline direction (1,0) within 0.001 and no skew, else `EDIT_ROTATED_TEXT` (any /Rotate is fine if the text displays upright; generalizes HDDN's unrotated-page rule). Replacement text: CRLF/CR -> LF; per line keep leading-space indent, collapse interior whitespace to one space, drop trailing whitespace; NFC. Allowed: U+000A, U+0020-007E, U+00A0-024F, U+0250-036F, U+1E00-1EFF, U+2000-206F minus bidi controls (U+200E-200F, U+202A-202E, U+2066-2069), U+20A0-20CF, U+2100-214F, U+2C60-2C7F, U+A720-A7FF, U+FB00-FB06; else `EDIT_UNSUPPORTED_SCRIPT {chars}`.
### 6.2 Metrics (display points; HDDN normalizes via §2)
Style = first selected cluster's; `mixedStyle` = >1 distinct (fontRef, size, color, flags). `originX` = min x of first-line clusters; `top` = min y of selected quads; `firstBaseline` of the first line. `lineStep` = median of baseline deltas > 1 pt between consecutive selected lines, else `1.2*fontSize`. `wrapRight` = max quad x of visible clusters on the page, unless a non-selected word on a vertically overlapping line starts right of the paragraph, then the paragraph's max x; `wrapWidth = wrapRight - originX`. `bottomLimit` = top of the nearest non-selected word below the last baseline overlapping [originX, wrapRight] in x, else `H - (min y of visible clusters)`. `descent = |d|*fontSize`. `maxLines = floor((bottomLimit + 0.1 - firstBaseline - descent) / lineStep) + 1`; `maxHeight = bottomLimit - top`. `originalText`: selected clusters in text order with overprint de-dup (drop a cluster with the same Unicode overlapping the previous one's quad by >= 50%, fixing faux bold), lines joined by LF; null if any selected cluster is unmapped.
### 6.3 Layout and apply (Rust is authoritative; DOM input edits text only)
Fixed font size. Greedy breaking after U+0020 (consumed) and after `-`/U+2010; LF hard break; a word wider than wrapWidth or more than maxLines lines -> `EDIT_NO_FIT {neededLines, maxLines}`. Line k baseline = `firstBaseline + k*lineStep`, x = originX + leading indent advance. Apply = remove selected source clusters (text only; images, vectors, backgrounds untouched, no fill) + append the planned runs as a new content stream (page content wrapped `q ... Q`, new text on top), fill color, mode 0. Registered fonts are written as Type0/Identity-H subsets (subsetter 0.2.6) with ToUnicode and /W, one font object per (fontId, document).
### 6.4 Font ladder per cluster (deterministic, recorded in `layouts[].runs`)
1. `TextEdit.font` (HDDN `localFontPick`) if it covers the cluster. 2. Source font reused as-is if it is simple or Identity CID with an invertible code<->Unicode map for the cluster and the glyph exists (advances from /Widths or /W, no shaping/kerning). 3. Registered font via `fontMatch` on the normalized source name, first match wins; DEFAULT_FONT_MATCH = HDDN table: calibri->Carlito, cambria->Caladea, georgia->Gelasio, times|roman|minion|garamond->Liberation Serif, courier|consol|mono->Liberation Mono, arial|helvetica|verdana|tahoma->Liberation Sans; weight/style from flags. 4. By flags: mono -> Liberation Mono, serif -> Liberation Serif, else Liberation Sans (as registered). 5. Else `EDIT_NO_FONT {chars}`. No Base-14 rung. Registered fonts are shaped with harfrust 0.14 defaults, LTR, Latin. `approximate` = any cluster not in the source font. `editorFace` (on request): registered font bytes, or an embedded TrueType/OpenType program with rebuilt (3,1) format-4 cmap + OS/2 (HDDN `_repair_font_for_browser`); CFF/Type1/Type3 -> null.

## 7. Raster export
Requires `policy.raster.acknowledgeLosses === true` (else `CONSENT_REQUIRED`) and every page rendering `complete` (else `RENDER_INCOMPLETE {pages}`); independent of native vector/pattern support. Per page of the current revision: render at `scale` (2 = 144 dpi, `maxRenderPixels` applies), annotations per policy, burn regions (every touched pixel gets the fill, white if null), encode 8-bit RGB Flate, write one image per page of W x H points (MediaBox [0 0 W H], no /Rotate). No text, fonts, annotations, metadata or Info. Losses `TEXT_SEARCH_LOST`, `VECTOR_RASTERIZED` plus each §8 item present. Verify = page count + zero clusters.

## 8. Sanitization (native; raster drops everything by construction)
### 8.1 Allowlist writer

Catalog: Type, Pages. Page: Type, Parent, MediaBox, CropBox, Rotate, UserUnit, Resources, Contents, Group. Resources: Font, XObject, ExtGState, ColorSpace, Pattern, Shading, Properties (sanitized), ProcSet. Image: Type, Subtype, Width, Height, ColorSpace, BitsPerComponent, Filter, DecodeParms, Decode, ImageMask, Mask, SMask, SMaskInData, Interpolate, Intent. Form: Type, Subtype, FormType, BBox, Matrix, Resources, Group, Filter, DecodeParms. Font, descriptor, CMap, encoding, ExtGState, color space, pattern, shading, function: their spec keys only. `%PDF-1.7`, classic xref, no object streams, no /ID, /Info or /Encrypt. ## 9. Limits
```ts
interface Limits {               // SDK default / HDDN adapter
  maxInputBytes: number;         // 64 MiB / 25 MiB
  maxPages: number;              // 1000 / 30
  maxObjects: number;            // 1_000_000
  maxStreamDecodedBytes: number; // 128 MiB per stream; an image XObject may decode to its declared size (ADR 0010), at most maxImagePixels x 4 components x 16 bit
  maxDecodeRatio: number;        // 1000, enforced once decoded > 1 MiB, not on image XObjects (flat scans deflate ~1030:1; maxImagePixels bounds them)
  maxImagePixels: number;        // 100_000_000 per image
  maxRenderPixels: number;       // 50_000_000 per render / raster page
  maxNesting: number;            // 32 Form/Type3/pattern/appearance depth (object nesting fixed 256)
  maxWorkUnits: number;          // 5_000_000_000 per operation
  maxOutputBytes: number;        // 256 MiB incl. writer buffer and transfer copy
  maxOpenDocuments: number;      // 4 / 2 (current + staged candidate)
  maxRegisteredFontBytes: number;// 64 MiB
}
```
Work unit = one interpreted operator, 1 KiB decoded/encoded, 1,000 pixels, or one shaped cluster. Exceeded -> `LIMIT_EXCEEDED {limit, actual, max}`, no output. WASM allocation failure -> reset (reason `oom`), `OUT_OF_MEMORY`.

## 10. Runtime
### 10.1 Worker and stepping
One module worker per client running one single-threaded wasm-bindgen module; no SAB, COOP/COEP, OffscreenCanvas or GPU. Many documents per worker. One op at a time, FIFO; queued ops cancel before start. Long ops are Rust state machines `step(budget = 100_000 units) -> Pending(Progress) | Done(T)`; between steps the worker yields via MessageChannel and checks cancellation. Ops are transactional: cancel/failure leaves state unchanged.
### 10.2 Hard reset
The supervisor terminates the worker after `hangTimeoutMs` without any message during an op, on worker `error`, on OOM, or on `restart()`. Then `generation+1`; pending promises reject `WORKER_RESET` (recoverable); old handles/plans are dead (`DOCUMENT_GONE`); registered fonts are re-sent from client-held bytes; `onReset` fires. A result never received = op not done; ops have no effects outside worker memory, so the caller reopens its bytes and re-applies its ChangeSet. `close()`/`dispose()` release owned memory and caches; not a physical wipe (wasm memory never shrinks; `restart()` returns it).
### 10.3 Assets
The wasm embeds hayro's std-14 substitute fonts (needed synchronously for rendering and for extraction metrics of non-embedded base fonts, which are common; about 0.3 MB of the spike's 0.57 MB gz asset delta) and no predefined CMaps. CMaps are a versioned pack of plain Adobe CMap resources `cmaps/<name>.cmap` (63 files, 3.19 MB raw; the `.bcmap` format of the first draft needs the 0.25 MB embedded table bundle, so it is not used), shipped in the npm package; `cmapsUrl` defaults to the package folder resolved from the worker's URL. At `open` the SDK fetches the `cmap:<name>` entries of `requiredAssets` (and their `usecmap` bases) and registers them with the engine (`registerCMap`) before the first page is read; fetch failure or a corrupt file -> `ASSET_LOAD_FAILED` at open with `details.feature = "cmap:<name>"`; a name outside the predefined set -> `CMAP_MISSING` warnings. **Status (NEW-88): implemented, `docs/deployment.md#cmapsurl`.** Identity-H/V need nothing. Static hosting, versioned names, CSP `script-src 'self' 'wasm-unsafe-eval'; worker-src 'self'`. Prepared offline = caller caches wasm, worker and pack.
### 10.4 Protocol envelope (`packages/sdk/src/protocol.ts`)
```ts
type Req = { v: 1; id: number; gen: number; op: OpName; doc?: string; args: unknown };
type Res = { v: 1; id: number; ok: true; result: unknown } | { v: 1; id: number; ok: false; error: ErrorWire };
type Prog = { v: 1; id: number; progress: { phase: 'open' | 'extract' | 'render' | 'layout' | 'export' | 'verify'; done: number; total: number } };
type Ctl = { v: 1; cancel: number } | { v: 1; event: 'ready' | 'fatal'; gen: number; reason?: string };
type ErrorWire = { code: ErrorCode; message: string; details?: ErrorDetails; recoverable: boolean };
```
Both sides validate every message at runtime (hand-written guards over generated types); bad `v`/`op`/shape -> `PROTOCOL_ERROR`; stale `gen` dropped. Input, font, render `data`, export and `editorFace` bytes travel as transferred ArrayBuffers copied out of wasm memory (never views). Document text is never logged.

## 11. Capabilities
`Capabilities = Record<'extract' | 'render' | 'edit' | 'redact' | 'exportNative' | 'exportRaster', { status: 'supported' | 'unsupported' | 'unknown'; reasons: { code: ErrorCode; pages?: number[] }[] }>`. `unknown` = not yet established. The fast check walks catalog/resources; `deep:true` interprets every page (bounded, cancellable). exportNative/exportRaster stay `unknown` until `prepareExport` succeeds or refuses (the only proof). `unsupported` always carries the code the op would return.

## 13. Rust surface
`foliark-engine::Engine::new(limits)` has one method per TS op (snake_case, same args, `DocId` handle). Long ops (`capabilities`, `extract_text`, `search`, `render`, `apply_changes`, `prepare_export`) return `Box<dyn Task<Out = T>>`; the rest return `Result<T, PdfError>`; `take_export(doc, plan_id) -> Result<Vec<u8>, PdfError>` backs `export`. `foliark-wasm` wraps it 1:1 (serde-wasm-bindgen args).
```rust
pub enum Step<T> { Pending(Progress), Done(T) }
pub trait Task { type Out; fn step(&mut self, e: &mut Engine, budget: u64) -> Result<Step<Self::Out>, PdfError>; }
```
`foliark-model` types: `Point{x,y}`, `Rect{x,y,width,height}`, `Quad([Point;4])`, `Matrix([f64;6])` (all f64), `ErrorCode`/`LossCode` (serde SCREAMING_SNAKE_CASE), `ErrorDetails`, `Limits`, `ExportPolicy`, and every §1 DTO (serde camelCase, ts-rs). Wire ids are strings.

### 13.1 Vendored hayro fork (`vendor/`, `[patch.crates-io]`, each change in `patches/hayro/README.md`, additive, upstreamable)
P1 operator byte spans (`UntypedIter/TypedIter::offset`) and per-content-stream identity instead of merged `page_stream`; P2 `Device::begin_operator(stream_id, range)` + Form `begin_form/end_form(obj_ref, matrix)` with an identity stack through Form/Type3/pattern/annotation recursion; P3 glyph raw char code + font `ObjRef` getters; P4 `InterpreterSettings::ocg_override` (interpret OFF content, report OC state); P5 strict decode (filter/decrypt failure or truncated Flate -> `Err`, never empty); P6 `Pdf::was_repaired()`.
