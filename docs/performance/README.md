# Performance baselines (NEW-8)

`baseline.json` (Chromium) and `baseline-webkit.json` (WebKit): same schema, HDDN worker vs Foliark SDK, same fixtures.
Numbers only; localhost, headless, identity encoding (wire bytes = file bytes). No speedup is claimed.

## Reproduce
Browser runs go through the memory queue (`--need-gb 2`; builds `--need-gb 4`). Queue events print to stdout, so use `--out`.

1. HDDN worktree (detached at 2fe0f9a; never touch `~/ai/repos/hddn`):
   ```
   git -C ~/ai/repos/hddn worktree add --detach .worktrees/hddn-2fe0f9a 2fe0f9a   # already exists
   cd .worktrees/hddn-2fe0f9a && pnpm install --frozen-lockfile && pnpm exec astro build
   ```
2. SDK: uses prebuilt `packages/sdk/dist` + `packages/sdk/wasm` (`pnpm build:wasm && pnpm build:sdk`); the bench never builds Rust.
3. Run (repo root):
   ```
   ~/ai/bin/memory-queue run --owner <id> --label 'foliark bench' --need-gb 2 --restartable --wait 1800 -- node tools/bench/run.mjs
   node tools/bench/run.mjs --browser webkit --out docs/performance/baseline-webkit.json
   node tools/bench/run.mjs --smoke      # N=2, 2 fixtures, writes tools/bench/.cache/smoke.json, exit 0
   ```
   Parts alone: `node tools/bench/hddn-worker.mjs`, `node tools/bench/sdk.mjs` (JSON on stdout).

## Method
- HDDN: real built worker (`dist/_astro/redactor.worker-*.js`) driven with its own protocol (INIT, LOAD_PDF + COMMIT_IMPORT, GET_PAGE_PREVIEW scale 1.35, APPLY_REDACTIONS native with one manual box, SET_TEXT_EDITS on one span).
- cold = fresh browser profile (empty HTTP cache), new worker; warm = same profile, new worker, assets cached (`bytes: 0` = nothing refetched).
- LOAD_PDF includes extraction and per-page previews. Per-page preview/render times are in `perPageMedianMs`.
- SDK: `createFoliark` init, `open`, `renderPage(scale 1.35)` per page, `close`. Everything else is listed under `unavailable`.
- Asset bytes come from the server's byte counter (`assets.hddn.runtime` = Pyodide + PyMuPDF; `fonts`/`ocr` are optional and not hit by these ops).
- Inputs: manifest fixtures `metadata-xmp`, `shared-image`, `rotation-crop`, plus `native-30p` generated by `tools/bench/make-native30.py` (PyMuPDF, dev-only; the manifest has no ~30-page text file). sha256 recorded.
- Memory: `performance.measureUserAgentSpecificMemory` throws in headless Chromium and is absent in WebKit, so only whole-browser process-tree RSS (`rssBytes`) is recorded. It is not JS heap.
- Schema 1: `{schema, createdAt, mode, machine, browser, engines, inputs[], measurements[{engine, op, input, run, ms (median), p95, n, bytes?}], assets, unavailable[], notes}`.
